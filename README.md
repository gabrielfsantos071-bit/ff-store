# FF STORE

Loja demo em Next.js para produtos digitais relacionados a Free Fire.

## Rodar localmente
1. Instale Node.js 18+.
2. Extraia o ZIP.
3. No terminal, dentro da pasta:
   npm install
   npm run dev
4. Abra http://localhost:3000

## Importante
Esta é uma base visual/funcional. O checkout atual é demonstrativo. Antes de receber dinheiro real, conecte um gateway autorizado, banco de dados, autenticação, webhooks e um método de entrega que seja permitido pelas regras do jogo e pelos fornecedores.

A loja usa identidade visual própria e não se apresenta como loja oficial da Garena.
